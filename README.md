## About

**Apple Bomb Snake** is a browser game inspired by the classic Snake on old phones. Guide the snake, eat apples to grow longer, and stay away from the walls, your own tail, and the **bomb apple** that appears at random.

No installation. No sign-up. Just open the link and play.

## Features

- 🐍 Classic Snake gameplay: eat apples and grow longer
- 💣 **Bomb apple** that appears at random. It looks like a real apple, so look carefully
- 🎚️ **Three levels:** Low, Medium and High, each with its own speed
- 🏆 **Best score saved** separately for each level
- 🎮 Simple keyboard controls (W A S D)
- 🟩 Pixel-art style with a retro screen look
- 🌙 Light and dark theme that follows your device
- 📱 Swipe controls on touch screens
- ⚡ One single HTML file, with no libraries or frameworks

## How to Play

1. Open the [live game](https://alkayadav93.github.io/Apple-Bomb-Snake/).
2. Choose a level: **Low**, **Medium** or **High**.
3. Press **W**, **S** or **D** to start moving.
4. Eat the red apples to score points and grow longer.
5. Do not eat the **bomb apple**. It ends the game right away.

### Controls

| Key | Action |
| --- | --- |
| **W** | Move up |
| **A** | Move left |
| **S** | Move down |
| **D** | Move right |
| **Space** | Pause, resume, or restart after Game Over |

On a phone or tablet, swipe on the game board to turn, and tap the board to pause.

### Levels

| Level | Speed | Bomb apples |
| --- | --- | --- |
| Low | Slowest, easy to learn | Appear less often |
| Medium | Normal | Appear sometimes |
| High | Fastest, a real challenge | Appear more often |

The snake gets a little faster each time it eats, up to a top speed for that level.

### Game rules

- The game ends if the snake hits a wall.
- The game ends if the snake hits its own body.
- The game ends if the snake eats the bomb apple (**BOOM!**).
- The bomb apple is a little darker than a real apple and has a burning spark on top instead of a green leaf. It blinks before it disappears.
